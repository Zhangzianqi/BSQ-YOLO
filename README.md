# BSQ-YOLO: Progressive Semantic Feedback with Information Preservation for Small Floating Litter Detection

This repository is the official project page for our paper:
> **Progressive Semantic Feedback with Information Preservation for Small Floating Litter Detection**

## Overview
- **Model (`BSQ-YOLO`)**: A YOLO11n-based detector featuring the Detail-Preserving Mixed-Attention Backbone (**DMAB**), Blur-Aware Semantic Query (**BSQ**) progressive semantic feedback, Semantically Guided Detail-Preserving Fusion (**SGDF**), and Wavelet-Guided Detail-Reparameterization Detection Head (**WDRH**).
- **Dataset (`SFLD`)**: The **Small Floating Litter Dataset (SFLD)** contains 2,939 images with 9,844 annotated instances across six categories (`bottles`, `cans`, `cups`, `boxes`, `plastic bags`, and `other litter`), where small objects account for over 74% of all instances.
